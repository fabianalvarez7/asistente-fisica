## Gotchas nuevos descubiertos (consolidados en `docs/hf-space.md`)

1. **Apple Git 2.50.1 no invoca filtros LFS** durante `git add`. Workaround: `git lfs clean` manual sobre cada binario antes de stagging.
2. **HF ya no acepta `user:password@host`** en URLs para push (sí para fetch). Workaround: credential helper con el token escrito a archivo.
3. **El rsync borra las reglas LFS del `.gitattributes` del Space** (porque el source lo tiene vacío). Sin esas reglas, el bake queda como LFS pointer ASCII en el contenedor y ChromaDB crashea al arranque con `(code: 26) file is not a database`. Workaround: `--exclude='.gitattributes'` en el rsync.

### Indexar los 4 capítulos nuevos al RAG

Los archivos están en `data/pdfs/`:

```
Cuerpo rígido.pdf
Momento Lineal y choques .pdf
Movimiento periódico.pdf
Trabajo y energía.pdf
```

**Estrategia recomendada: de a uno**, no todos juntos. Razones:

- `scripts/indexar_pdfs.py --pdf <path>` procesa un PDF específico. El script es **idempotente**: detecta por `metadata.source` los ya indexados y los skipea.
- Permite punto de control entre capítulos. Si uno falla (formulas rotas, encoding), no perdés los otros.
- El bake hay que regenerarlo y redeployarlo al Space después. Si falla, sabés qué capítulo fue.

**Orden sugerido:**

```bash
# Validar que están los 4 archivos
ls "data/pdfs/" | grep -v "Contenidos Temáticos"

# Indexar de a uno
python scripts/indexar_pdfs.py --pdf "data/pdfs/Cuerpo rígido.pdf"
python scripts/indexar_pdfs.py --pdf "data/pdfs/Momento Lineal y choques .pdf"
python scripts/indexar_pdfs.py --pdf "data/pdfs/Movimiento periódico.pdf"
python scripts/indexar_pdfs.py --pdf "data/pdfs/Trabajo y energía.pdf"

# NO indexar Contenidos Temáticos.pdf — es el syllabus, ya lo usa /topics.

# Re-bakear y redeploy al Space
rm -rf rag/index/chroma && cp -r data/chroma rag/index/chroma/
# después seguir el workflow de docs/hf-space.md
```
